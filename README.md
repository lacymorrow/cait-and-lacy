# Cait and Lacy

A personal wedding site for Cait and Lacy. Features an interactive image compare slider that cycles through photos.

## Features

- Interactive photo compare slider (drag to reveal)
- Auto-cycling through multiple photos
- Link to the wedding website at [theknot.com/caitlynandlacy](https://theknot.com/caitlynandlacy)

## Tech Stack

Built with the [T3 Stack](https://create.t3.gg/):

- [Next.js](https://nextjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [tRPC](https://trpc.io)

Bootstrapped with `create-t3-app`.
